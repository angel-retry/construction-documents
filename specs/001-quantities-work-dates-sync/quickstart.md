# Quickstart & Verification Guide: 數量看板顯示日期連動

## 驗證流程 (Verification Steps)

### 步驟 1：啟動開發伺服器
若尚未啟動，於 `web/` 目錄執行：
```bash
pnpm dev
```
造訪目標網址：
`http://127.0.0.1:3100/projects/f3c19986-aa58-47b9-b6f3-01e8545c49a0/quantities?year=115&month=9`

---

### 步驟 2：測試預設連動顯示
1. 進入該標案的施工路段頁面（`/sites?year=115&month=9`）。
2. 在第一個路段設定施工日期（例如利用月曆挑選 `9/5、9/10~9/12` 並儲存）。
3. 點擊分頁切換至「每日數量與帳務總覽」（`/quantities`）。
4. **驗收預期結果**：
   * 該路段表格橫向欄位預設僅顯示 `9/5`、`9/10`、`9/11`、`9/12` 共 4 欄。
   * 下拉選單摘要清楚標註當前依施工日期顯示。

---

### 步驟 3：測試自訂篩選與還原
1. 在路段內點開「顯示日期」下拉選單。
2. 勾選非施工日（例如 `9/1`、`9/2`）。
3. **驗收預期結果**：表格立即切換為僅顯示 9/1、9/2。
4. 點擊「依施工日期顯示」按鈕。
5. **驗收預期結果**：表格恢復僅顯示 `9/5`、`9/10`、`9/11`、`9/12`。
